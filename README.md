# Sheffield Air Quality Analysis 2024

Visual analysis of PM2.5 pollution patterns in Sheffield during 2024.

## Overview
This repository contains data, code, and visualisations for analyzing PM2.5 
particulate matter concentrations in Sheffield, UK from January to October 2024.

## Data Source
- **Platform:** OpenAQ (https://openaq.org)
- **Station:** Sheffield Devonshire Green (ID: 2508)
- **Coordinates:** 53.378622°N, 1.478096°W
- **Period:** 1 January 2024 - 27 October 2024
- **Observations:** 5,990 hourly measurements

## Key Findings
- Annual mean: 7.41 µg/m³ (48% above WHO guideline)
- 329 extreme pollution events identified (≥95th percentile)
- Peak concentrations in March (10.52 µg/m³ median)
- Highest extreme event frequency in September (124 hours)

## Repository Contents
- data: Raw and processed datasets
- code: R scripts for analysis and visualisation
- figures: Generated visualisations (PNG, 300 DPI)

## Requirements
- R (≥4.3.0)
- Packages: dplyr, tidyr, lubridate, ggplot2
